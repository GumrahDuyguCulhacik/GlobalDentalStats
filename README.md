## Ziel des Projekts
Analyse der zahnmedizinischen Gesundheitsausgaben der Länder

Zusammenführung und Aufbereitung der WHO‑Datensätze zu Mundgesundheitsindikatoren

Untersuchung der Mundkrebsfälle auf globaler Ebene

Gruppierung der Länder mittels Clustering‑Methoden (K‑means) und Klassifikationsmodellen basierend auf Gesundheitsausgaben

Schätzung des durch Mundkrankheiten verursachten Produktivitätsverlustes mithilfe von Regressionsmodellen

## Verwendete Methoden
# 1. Datenbereinigung und Zusammenführung
Analyse der WHO‑Datensätze aus dem Bereich Dental Indicators

Auswahl relevanter Datensätze

Zusammenführung über gemeinsame Variablen

Aufbau einer konsistenten und aussagekräftigen Datenstruktur für die Analyse

# 2. Explorative Datenanalyse (EDA)
Deskriptive Statistiken

Analyse der Variablenverteilungen

Korrelationsanalysen

# 3. Clustering‑Analyse
Bildung von Ländergruppen mittels K‑means

Erstellung von Clusterprofilen

Visualisierung der Cluster mittels Heatmaps

# 4. Regressionsmodelle
Modellierung des durch Mundkrankheiten verursachten Produktivitätsverlustes

Untersuchung der Zusammenhänge zwischen wirtschaftlichen Indikatoren und Gesundheitsdaten

## Zentrale Erkenntnisse
Zwischen Mundgesundheitsindikatoren und wirtschaftlichen Faktoren bestehen deutliche Zusammenhänge

Länder mit hohen Gesundheitsausgaben bilden klar erkennbare Cluster

Mundkrebsfälle zeigen je nach Einkommensgruppe unterschiedliche Muster

Produktivitätsverluste spiegeln die wirtschaftliche Bedeutung von Mundkrankheiten wider
